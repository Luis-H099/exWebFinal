# exWeb Final

Projeto desenvolvido em ASP.NET Core MVC com C#, Entity Framework Core e SQL Server.

## Versão principal

Este repositório reúne a versão mais recente do projeto, originalmente publicada como `exWeb007`.

A versão mais recente inclui a evolução do sistema de alunos e professores e o início da implementação do gerenciamento de turmas.

> Observação: a implementação de turmas ainda precisa de ajustes e validação. Este repositório preserva o estado do código publicado, sem afirmar que todas as funcionalidades estejam concluídas ou compilando.

## Histórico de versões

As versões anteriores foram preservadas nas pastas abaixo:

- `Versoes-antigas/exWeb001/`
- `Versoes-antigas/exWeb002/`
- `Versoes-antigas/exWeb003/`
- `Versoes-antigas/exWeb004/`
- `Versoes-antigas/exWeb005/`

Os arquivos de código e configuração foram mantidos dentro de cada pasta para consulta do histórico de desenvolvimento. Arquivos compactados duplicados (.zip/.rar) e `desktop.ini` não foram incluídos.

## Versão anterior mantida separadamente

A versão `exWeb006` permanece em seu próprio repositório como referência da etapa anterior, com o gerenciamento de alunos e professores.
